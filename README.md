# 한국어 업무 작성 스킬

한국어 글·업무 문서·Slack 문구를 작성하고, 수정하고, 검토하는 Agent Skill이다. 독자가 이해하거나 판단하거나 행동하는 데 필요한 정보를 정리하되, 원문에 있는 사실·수치·조건·부정·확신의 정도와 사용자 의도를 보존한다.

첫 정식 판본은 **v0.1.0**이며 [MIT 라이선스](LICENSE)로 제공한다. [릴리스에서 설치 ZIP과 체크섬을 내려받을 수 있다](https://github.com/monancho/korean-writing-skill/releases/tag/v0.1.0).

## 이렇게 요청한다

```text
$korean-writing으로 다음 Slack 문구를 공손하고 간결하게 다듬어 주세요.
조건과 가능성은 유지하고 수정본만 주세요.
원문: 검토가 끝나면 게시 여부를 논의할 수 있습니다.
```

다음은 설명을 위한 가상 수정 예다.

> 검토를 마치면 게시 여부를 논의할 수 있습니다.

검토가 끝나야 한다는 조건과 게시 여부를 논의할 수 있다는 가능성을 유지한다. 게시가 확정됐다는 뜻으로 바꾸지 않는다. 이미 적절한 문장은 그대로 둘 수 있다.

| 필요한 작업 | 요청 예 | 기본 결과 |
|---|---|---|
| 작성 | 제공한 자료로 업무 보고 초안을 작성해 주세요. | 요청한 글 |
| 수정 | 원뜻과 조건을 유지하며 이 문구를 다듬어 주세요. | 수정본 |
| 검토 | 문제 위치와 이유만 알려 주세요. 재작성은 하지 마세요. | 문제·이유·수정 방향 |

결합된 요청은 사용자가 지정한 순서와 범위로 처리한다. 점수·등급·긴 변경표는 기본 출력에 넣지 않는다.

## 설치하기

1. [v0.1.0 릴리스](https://github.com/monancho/korean-writing-skill/releases/tag/v0.1.0)에서 `korean-writing-0.1.0.zip`과 `SHA256SUMS.txt`를 받는다.
2. ZIP의 SHA256을 체크섬과 비교한 뒤 새 폴더에 압축을 푼다.
3. `korean-writing/` 폴더 전체를 사용할 프로젝트의 `.agents/skills/` 아래에 복사한다. 같은 이름의 스킬이 있으면 먼저 내용과 판본을 비교한다.

설치 ZIP에는 스킬 파일 7개, `LICENSE`, 파일별 해시를 담은 `manifest.json`이 들어 있다. 스킬 사용에는 Python이 필요하지 않다. 저장소에서 직접 복사하는 방법, PowerShell 명령, 호출 예시는 [사용 안내](docs/usage.md)에 있다.

## 확인한 범위

공식 스킬 검사, 구성 검사, 자동 시험 10개, 반복 빌드와 파일 해시, 격리된 프로젝트 설치 복사, 정식 릴리스의 로그인 없는 다운로드를 확인했다.

28개 가상 사례는 작성자 직접 적용·도구 없는 환경의 경계 대응·파일 정적 확인을 구분한 기록이다. 독립적인 글 품질 평가, 설치된 제품의 자동 스킬 선택, 다른 환경의 실제 설치, 실사용 효과는 확인하지 않았다. 방법과 실제 결과는 [검증 보고](docs/verification-report.md)에 있다.

문서 파일 생성이나 외부 발송에는 실제 환경의 별도 도구와 사용자 위임이 필요하다. 이 스킬은 글을 다듬는 지침이며 그 권한을 대신하지 않는다.
