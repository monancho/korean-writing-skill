# 한국어 업무 작성 스킬

한국어 글·업무 문서·Slack 문구의 작성, 수정, 검토를 돕는 지침형 Agent Skill이다. 사실·수치·조건·부정·확신의 정도와 사용자 의도를 보존하는 것을 우선한다.

현재 비공개 개발 저장소이며 구현을 순서대로 진행한다. 공개 여부와 배포 라이선스는 별도 결정 대상이다. 단계별 설계·구현·검증·인계 기록은 `docs/`에 남긴다.

첫 설계 기준은 [아키텍처 결정](docs/adr/0001-entrypoint.md)과 [구현 계획](docs/implementation-plan.md)이다. 아직 확인하지 않은 기능이나 효과를 구현 완료로 표시하지 않는다.
