# 스킬을 적용한 저장소 문서 편집 기록

2026-10-12 Asia/Seoul, 사용자의 요청에 따라 korean-writing 스킬을 저장소 문서에 직접 적용했다. 독자는 설치하려는 사용자, 수정 기여자, 설계와 검증 근거를 확인할 사람으로 나눠 문서 순서를 정했다.

## 적용 방법과 산출물

핵심 SKILL.md와 한국어 표현·문서·메시지·근거·예시 참조를 읽고 “수정·재구성” 요청으로 처리했다. 기존 문서 15개를 정리하고 [개발 문서 색인](README.md)과 이 기록을 추가했다. 출처 대장은 탐색과 후속 결정 연결을 추가했으며 69개 항목의 관찰 본문은 보존했다.

| 읽는 목적 | 구성한 문서 |
|---|---|
| 설치하고 첫 요청하기 | 저장소 README·사용 안내 |
| 제안하고 수정하기 | 기여 안내·변경 기록 |
| 결정과 구현을 추적하기 | 구현 계획·ADR·요구사항 추적·구현 기록 |
| 확인 수준과 배포 조건 파악하기 | 검증 보고·출처/자산·고지·공개 점검·릴리스 인계 |
| 조사 근거 찾기 | 조사 자료 안내·출처 대장 |

## 실제 편집 예

| 위치 | 기존 구성·문구 | 편집한 결과 | 보존한 조건 |
|---|---|---|---|
| README | 용도·구현 구성 뒤 설치 링크와 개발 산출물 목록 | 용도와 정식 판본 → 요청 예 → 설치 → 확인 범위 → 목적별 링크 | MIT·v0.1.0·28개 직접 적용의 한계·외부 도구 경계 |
| 사용 안내 | 저장소 직접 복사 후 릴리스 설치 안내 | 릴리스 ZIP 경로를 먼저 안내하고 저장소 복사는 별도 절로 이동 | 체크섬·LICENSE·전체 폴더·기존 스킬 비교·원래 PowerShell 명령과 요청 예 |
| 요구사항 추적 | 9행마다 같은 “호스트 자동 선택·효과는 미확인” 설명 | 공통 확인 범위를 표 앞에 한 번 명시 | R1–R9·K/B·TC 대응과 구현 책임 |
| 릴리스 인계 | “변경·검증·PR 병합·게시·재조회를 수행한다” | 실제 수행 결과와 태그 커밋·HEAD CI·자산 해시 연결 | 최초 계획은 계획 기록에 유지. 완료 시제는 실제 게시 증거로 확인 |
| 출처 대장 | S01–S69 순서, 끝에 MIT 후속 결정 | 주제별 링크와 후속 결정 안내를 앞에 추가 | 기존 항목의 판본·열람 범위·관찰·적용·한계 |

문장 표현만 바꿔서 계획을 완료로 쓰지는 않았다. 릴리스 결과는 이미 확인한 GitHub 원본으로 대조했고, 후보 당시의 미결 기록은 이력으로 표시했다.

## 보호한 내용

69개 출처·284개 목적 분석 항목의 수와 의미를 유지했다. 28개 관찰은 문장·문서 25개, 도구 없는 경계 2개, 실제 파일 정적 확인 1개로 구분했다. 최초 후보의 자동 시험 8개와 MIT 변경 후 10개도 단계별로 구분했다. 설치 ZIP의 스킬 파일 7개·LICENSE·manifest와 MIT 조건은 그대로다.

인용·오류 식별자·TC 결과·연구 원본 JSON/CSV·스킬 지침·라이선스·개발 스크립트·시험·v0.1.0 태그와 게시 자산은 수정하지 않았다. 독립 검토·호스트 자동 선택·사용성 수락·효과 수치·확정 일정의 미확인 상태도 유지했다.

## 확인 범위

문서 구조와 문장을 바꾼 작성자가 같은 컨텍스트에서 원자료와 직접 대조했다. 구성·링크 검사와 기존 자동 시험은 파일의 무결성을 확인하며 문장 품질이나 개선 효과를 입증하지 않는다. 독립 검토나 설치된 제품의 자동 호출 사례로 세지 않는다.

이번 편집에서 구성·상대 링크 검사와 기존 자동 시험 10개가 통과했다. TC01–TC28의 관찰 표, S01–S69의 출처별 본문, R1–R9의 대응, 사용 안내의 명령·요청 예를 기존 판본과 대조해 보존을 확인했다. 출처 대장의 새 앵커가 실제 항목을 가리키는지도 확인했다.

설치 ZIP을 다시 생성한 SHA256은 `8714377fdcc22d6da357e8c1903889141d115e59918facb9999b3b7cb5b24cd2`로 v0.1.0 게시 자산과 같다. 이 해시는 스킬·LICENSE의 배포 바이트 확인이며 문장 개선 효과의 지표가 아니다.

편집의 정확한 HEAD와 CI는 [변경 PR](https://github.com/monancho/korean-writing-skill/pulls)와 해당 Checks를 원본으로 연결한다. v0.1.0 태그와 릴리스 파일은 정식 판본의 원본으로 유지하고 이번 문서 편집은 저장소의 후속 변경으로 기록한다.
