# ADR-001 — 한 진입점과 조건부 참조

상태: 이 구현의 기술 설계 기준. 작성: Codex, 2026-10-12 Asia/Seoul. 사용자가 기존 문서에 기반한 순차 구현을 요청하고 비공개 저장소 생성을 선택한 단계에서 결정했다. 장기 운영 정책의 채택·공개 결정·효과 검증의 수락과 구분한다.

## 맥락과 판단 기준

작성·수정·검토는 의미 보호 규칙을 공유하지만 결과는 다르다. 짧은 문구에 장문 공동 집필 절차를 강제하거나 모든 참조를 읽으면 요청 범위를 넘기 쉽다. 공통 규칙을 모드마다 복제하면 개정 후 불일치가 생길 수 있다.

공통 규칙의 일관성, 요청 모드의 구분, 필요한 내용만 읽기, 특정 회사·도구와 무관한 재사용을 기준으로 구성을 비교했다.

## 대안

| 대안 | 이점 | 비용·조건 |
|---|---|---|
| 모드별 스킬 세 개 | 호출 목적을 구분하기 쉬움 | 공통 의미 규칙이 중복되고 결합 요청에서 여러 스킬을 읽음 |
| 하나의 큰 파일 | 참조 누락이 적음 | 간단한 요청에도 장문 규칙을 전부 읽음 |
| 한 진입점과 조건부 참조 | 공통 규칙을 한 곳에서 관리하고 필요한 상세만 읽음 | 실제 요청에 맞게 참조를 선택하는지 확인 필요 |

## 선택과 영향

한 진입점과 조건부 참조를 선택했다. `SKILL.md`에 의미 계약·모드·입력 부족 처리·최종 대조를 두고, 문서·메시지·한국어 표현·근거·예시를 별도 참조에 둔다. 독자·목적·정보 순서의 공통 판단은 핵심과 문서 참조에 포함하므로 별도 `principles.md`를 만들지 않는다.

참조는 상대 경로를 사용하며 내부 운영 정책이나 계정 연결을 요구하지 않는다. 이 지침으로 파일 생성·외부 발송·승인 권한을 얻지는 않는다.

## 확인과 재검토 조건

불필요한 참조 강제, 공통 규칙 충돌, 필수 규칙 누락이 관찰되면 구성을 재검토한다. 공개 사례의 모드 구분과 점진적 로딩을 참고한 자체 설계 선택이며, 개선 효과나 다른 대안보다 우월함을 검증한 결과는 아니다. 출처별 관찰·적용·한계는 [출처 대장](../../research/source-register.md)에 있다.
