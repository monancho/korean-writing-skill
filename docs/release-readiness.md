# 공개 결정과 릴리스 인계

결정일: 2026-10-12 Asia/Seoul. 결정 상태: 사용자 위임에 따른 공개·MIT 확정·첫 정식 릴리스 `v0.1.0`.

## 결정 기록 — DACI 형식

| 역할/항목 | 실제 내용 |
|---|---|
| 결정 권한 | 실제 사용자가 기존 프로젝트의 공개·라이선스 확정·정식 릴리스를 명시적으로 위임했다. |
| 실행과 선택 | Codex가 위임 범위에서 MIT와 `v0.1.0`을 선택하고 변경·검증·PR 병합·게시·재조회를 수행한다. |
| 기여/통지 | 별도 검토자나 기한을 지정하지 않는다. 저장소 소유자는 monancho다. |
| 대상 | 기존 `monancho/korean-writing-skill`, 공개 저장소와 정식 GitHub Release. |
| 선택 이유 | 자체 작성 지침·코드·예시의 재사용을 허용하면서 저작권/허가 고지를 유지하는 단순한 배포 조건. |
| 대안 | Apache-2.0의 명시 특허 조항 등을 비교했으나 이 판본에는 적용하지 않았다. |
| 영향 | 저장소 파일·이력·PR·CI 로그·작성자 메타데이터가 공개된다. 외부 원출처의 권리를 바꾸지 않는다. |

[MIT 원문](https://opensource.org/license/mit)을 `LICENSE`에 반영하고 스킬 메타데이터와 ZIP manifest를 MIT로 맞췄다. 공개 자료의 권리 경계는 [고지](../NOTICE.md)에 있다. 이전 비공개 구현 후보 단계의 라이선스 미결·공개 미수행 기록은 당시 이력이다.

## 정확한 배포 구성

| 자료 | 포함 범위 | 확인 방법 |
|---|---|---|
| 설치 ZIP | SKILL.md·참조 5개·UI 메타데이터·LICENSE: 총 8개 파일, 별도 manifest.json | 정확한 경로/개수·파일별 SHA256·MIT 본문·반복 빌드 동일성 |
| SHA256SUMS.txt | 설치 ZIP 전체의 SHA256과 파일명 | 익명 다운로드한 실제 ZIP으로 다시 계산 |
| 저장소/소스 아카이브 | skills·scripts·tests·CI·문서·외부 링크/자체 메모·목적 분석·고지 | 공개 범위·Git 이력·PR·CI 로그 직접 확인 |
| 실행 증거 | PR의 정확한 HEAD·병합 commit·현재 main CI·태그·릴리스 속성·게시 자산 | GitHub 원본 재조회 |

## 게시와 인계 절차

1. 라이선스/패키지 변경을 PR로 검토 가능하게 만들고 공식 검증·구성 검사·10개 시험·ZIP 설치 파일 대조를 수행한다.
2. 정확한 PR HEAD의 CI 성공 후 현재 위임으로 병합하고 병합 후 main CI와 파일 동일성을 확인한다.
3. 병합 판본에 `v0.1.0` 태그를 연결하고 ZIP·SHA256SUMS.txt·한국어 안내를 준비한다. 공개 범위 확인 후 저장소를 공개하고 정식 릴리스를 게시한다.
4. 인증 없는 조회로 저장소 public·태그 commit·릴리스 draft=false/prerelease=false·자산 해시/내용을 확인한다. 실제 게시 결과는 [릴리스](https://github.com/monancho/korean-writing-skill/releases/tag/v0.1.0)와 PR/Actions를 원본으로 남긴다.

독립 순방향 시험·사람 사용성 평가·호스트 자동 선택·효과 수치·확정 일정은 이 릴리스의 완료 조건에 포함하지 않는다. 확인 수준은 [검증 보고](verification-report.md)에 있다. 결함 제보는 저장소 Issues로 받으며 미지정 응답 기한을 만들지 않는다. 공개 이후 이미 내려받은 사본의 회수는 보장하지 않는다.
