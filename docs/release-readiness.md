# 공개 준비 결정과 인계

상태: 비공개 구현 후보 준비. 공개·라이선스 확정·정식 릴리스는 수행하지 않았다.

## 확인된 결정과 역할

실제 사용자가 새 저장소 생성·문서 기반 순차 구현·구현 중 산출물 작성을 명시했고 가시성으로 비공개 생성 후 공개 준비를 선택했다. 저장소는 `monancho/korean-writing-skill`이며 소유자는 monancho다. 공개·배포 라이선스의 결정 주체는 사용자, 후보 준비·구현·직접 확인 주체는 Codex다. 지정되지 않은 검토자·기한은 만들지 않는다.

## 검토 가능한 후보

| 범위 | 포함할 후보 | 확인 |
|---|---|---|
| 스킬 ZIP | SKILL.md·참조 5개·UI 메타데이터·manifest | 7개 파일의 해시와 정확한 구성, ZIP 재현성 |
| 저장소 소스 | skills/·scripts/·tests/·.github/workflows/·.gitignore·.gitattributes | UTF-8·상대 참조·경로 이탈·내부 URL 후보 검사 |
| 안내·개발 기록 | README·사용법·ADR·구현/검증/추적·출처·인계·변경 기록 | 실제 파일/판본과 대응 |
| 연구 자료 | 외부 출처 링크/메모·284개 템플릿 목적 분석 | 원문·내부 ID/URL 제외·열람 한계 표시 |

정확한 Git 판본과 CI는 PR의 HEAD와 Checks를 원본으로 사용한다. ZIP manifest는 포함한 스킬 파일별 SHA256을 기록한다. 공식 릴리스 파일·버전 태그를 게시한 것은 아니다.

## 라이선스 선택안

권장 후보는 MIT다. 자체 작성 지침·코드·예시의 재사용을 넓게 허용하고 저작권/허가 고지를 유지하는 비교적 단순한 조건을 원할 때 적합하다. [MIT 원문](https://opensource.org/license/mit)에 맞춰 사용자 결정 후 실제 LICENSE와 패키지 고지를 반영한다.

특허 관련 명시 조항을 포함한 대안을 원하면 [Apache-2.0 원문](https://www.apache.org/licenses/LICENSE-2.0)을 비교한다. 외부 원출처의 권리를 저장소의 새 라이선스로 덮어쓰지 않는다. 현재 LICENSE 파일이나 확정된 license 메타데이터는 없으며 manifest의 license_status는 UNDECIDED다.

## 다음 실행의 조건

1. 비공개 PR의 정확한 HEAD·CI·남은 검토 조건과 병합 위임을 확인한다. 병합 전후 스킬 내용의 해시와 main 반영을 확인한다.
2. 사용자 라이선스 결정 후 LICENSE·고지·manifest·안내를 함께 수정하고 영향 범위 검사와 후보 ZIP을 다시 만든다.
3. 공개 전환을 사용자가 결정하면 파일·Git 이력·자료 범위·가시성을 최종 확인하고 해당 범위만 공개한다.
4. 실제 설치·호스트 자동 선택·독립 순방향 사용 확인은 별도 기록한다. 효과·개선 수치·확정 일정을 이 인계로 만들지 않는다.
