# 출처와 배포 자산

자체 작성한 자료는 MIT로 배포하고, 외부 자료는 링크와 자체 요약·목적 분석으로 연결한다. 외부 자료를 읽은 사실과 그 원문을 재배포할 권리는 구분한다.

## 포함한 자료

| 자료 | 사용한 목적 | 포함 범위와 권리 |
|---|---|---|
| 자체 핵심 지침·참조 | 작성·수정·검토 판단 | 파일 전체, MIT |
| 자체 한국어 가상 사례 | 설명·직접 적용 확인 | 입력·결과·관찰. 실제 내부 문서 아님 |
| 자체 개발 스크립트·문서 | 구성 검사·패키지 생성·인계 | 파일 전체, MIT |
| 공개 작성 스킬 | 모드·구성·검토 방식 비교 | 판본 링크·자체 요약. 프롬프트·코드·원문 예시 제외 |
| 논문·표준·언어 지침 | 오류 범주·조건·규격 참고 | 서지·링크·열람 범위·자체 해석. PDF·유료 전문·원문 예시 제외 |
| Atlassian 페이지/블록 템플릿 | 목적·항목·재사용 책임 비교 | 자체 목적 분석·공식 링크. 템플릿 본문·내부 API ID/URL 제외 |
| GitHub Actions | 개발 CI의 체크아웃·Python 설정 | 고정 SHA 참조. 액션 코드는 번들하지 않음 |

외부 출처 대장은 69개 링크와 자체 메모를, 템플릿 목적 대장은 284개 분석 항목을 담는다. 출처별 판본·열람 범위·라이선스 관찰은 [출처 대장](../research/source-register.md)에 있다. 라이선스가 미확인인 외부 자료도 원문을 복제하지 않고 링크와 자체 요약으로 연결한다.

## 제외한 자료와 공개 이력

회사 운영 정책·Jira 계약·Confluence/Slack 원문·계정/채널 ID·Zotero 내부 키·개인 로컬 경로·인증정보·논문 PDF·타인 스킬 파일·네이티브 템플릿 본문은 제외했다.

저장소 파일과 Git 이력·PR·CI 로그·작성자 메타데이터는 사용자 위임의 공개 범위다. 확인 방법과 한계는 [공개 점검](publication-review.md)에 있다. 알려진 URL/경로 패턴 검사는 보조 수단이며 모든 민감정보 부재의 인증이나 모든 출처의 권리 확정이 아니다.

## 라이선스 고지

표준 MIT 전문은 루트 LICENSE와 설치 ZIP에 허가 고지로 포함한다. 자체 작성한 링크 설명과 요약에 적용하는 MIT는 외부 원출처의 권리를 바꾸지 않는다. GitHub Actions는 스킬 실행에 필요한 의존성이 아니라 개발 검사에 사용하는 도구다. [자료와 권리 고지](../NOTICE.md)를 함께 확인한다.
