# 출처·재사용 자산·포함 범위

## 실제 포함한 것

| 자료 | 역할 | 이번 포함 | 재사용 상태 |
|---|---|---|---|
| 직접 작성한 핵심 지침·참조 | 실행할 작성 판단 | 파일 전체 | 자체 작성·MIT |
| 직접 만든 한국어 가상 사례 | 사용 설명·직접 적용 확인 | 입력·결과·관찰 | 실제 내부 문서 아님 |
| 직접 작성한 개발 스크립트·문서 | 패키지 확인·인계 | 파일 전체 | 자체 작성·MIT |
| 공개 작성 스킬 | 모드·구성·검토 방식 비교 | 판본 링크·자체 요약 | 프롬프트·코드·예시 원문 제외 |
| 논문·표준·언어 지침 | 오류 범주·조건·규격 참고 | 서지·링크·읽은 범위·자체 해석 | PDF·유료 전문·원문 예시 제외 |
| Atlassian 페이지/블록 템플릿 | 목적·항목·재사용 책임 비교 | 자체 목적 분석·공식 출처 링크 | 원문 본문·내부 API ID/URL 제외 |
| GitHub Actions | 개발 CI의 체크아웃·Python 설정 | 고정 SHA 참조 | 액션 코드 미포함; 스킬 실행 의존 아님 |

출처별 기존 라이선스 관찰·판본·열람 범위는 [외부 출처 대장](../research/source-register.md)에 있다. 외부 자료를 읽은 사실과 원문을 재배포하는 권리는 구분한다. 라이선스 미확인 자료도 원문을 복제하지 않고 링크·자체 요약으로만 연결한다.

## 제외한 자료

회사 운영 정책·Jira 계약·Confluence 원문·Slack 원문·계정/채널 ID·Zotero 내부 키·개인 로컬 경로·인증 정보·논문 PDF·타인 스킬 파일·네이티브 템플릿 본문을 제외했다. 저장소 자료와 Git 이력·PR·CI 로그·작성자 메타데이터는 사용자 위임에 따른 공개 범위다. 정확한 확인 방법은 [공개 범위 기록](publication-review.md)에 있다.

자동 URL/경로 검사는 알려진 패턴의 후보를 잡는 보조 수단이다. 모든 민감 자료를 판별하는 인증이나 모든 출처의 법적 권리를 확정한 결과가 아니다. 외부 출처 69개의 링크·자체 메모에 적용하는 MIT는 원출처의 권리를 바꾸지 않는다. 표준 MIT 전문은 배포 허가 고지로 LICENSE에 포함하고 ZIP에도 복사한다.
