# 조사 자료 안내

스킬 설계에 참고한 공개 사례·연구·개발 규격·Confluence 기능을 연결한다. 자료에서 관찰한 내용, 스킬에 적용한 자체 판단, 읽지 않았거나 실행하지 않은 범위를 구분한다.

## 필요한 자료 찾기

| 자료 | 담은 내용 | 확인할 범위 |
|---|---|---|
| [출처 대장](source-register.md) | 외부 출처 69개의 링크·판본·열람·적용·한계 | 현재 해석과 출처 작성자의 주장 |
| [구조화 출처](sources.json) | 같은 외부 자료의 기계 판독 메모 | 내부 Zotero 키·개인 경로를 제외한 공개 자료 |
| [템플릿 목적 대장](template-purpose-catalog.csv) | 당시 연결에서 읽은 284개 항목의 형태·목적 분석 | 원문 본문·내부 API ID/URL을 제외한 자체 분석 |

284개 항목에는 같은 이름의 중복 항목과 매크로 보조 항목도 포함한다. 독립적인 실무 양식 284종이나 공개 갤러리의 전수조사로 해석하지 않는다.

## Double Diamond의 적용

| 단계 | 이 프로젝트에서 한 일 |
|---|---|
| Discover | 개발 프로세스·협업 문서·규격·템플릿·블록 기능을 넓게 조사 |
| Define | 의미·의도 보존과 다음 작업의 입력 연결로 현재 문제를 좁힘 |
| Develop | 여러 진입점·하나의 큰 파일·조건부 참조 구성을 비교 |
| Deliver | 구현·검증·사용 안내·공개 결정과 첫 정식 판본을 인계 |

비공개 후보 이후 공개·MIT·v0.1.0의 후속 결정을 기록했다. 이 흐름은 프로젝트에 맞춘 자체 설계이며 사용자 조사나 효과 측정을 수행했다는 뜻은 아니다. 실제 구현 대응은 [ADR](../docs/adr/0001-entrypoint.md)과 [요구사항 추적](../docs/requirements-traceability.md)에 있다.

## 열람과 적용의 한계

ISO 자료는 기존 조사에서 공개 개요·판본·상태를 확인한 범위다. 유료 전문의 의무 조항을 모두 읽거나 준수 인증을 수행하지 않았다. 현재 스킬은 특정 개발 프로세스나 템플릿 284개 항목의 전문을 강제하지 않는다. 원출처와 자체 배포 자료의 권리는 [출처·자산 범위](../docs/source-and-assets.md)에서 구분한다.
